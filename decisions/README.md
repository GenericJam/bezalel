# Decision log

One file per non-obvious decision: `YYYY-MM-DD-short-slug.md`, a lightweight
ADR (Context / Decision / Consequences). Append new files; never rewrite a
decision. If one changes, add a new file and mark the old one
`Status: superseded by <file>`. Correct a factual error in place, with a note
saying what was wrong. The rules are in AGENTS.md, "Decision log".
